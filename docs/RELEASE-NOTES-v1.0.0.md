# RUOK 1.0.0 - Windows x64 preview

The first versioned standalone release from `main`. No experimental testing-branch features are included.

## Download

Download **RUOK-v1.0.0-win-x64.exe**, save it in a permanent local folder, and double-click it. Requires **Windows 11 24H2 (build 26100) or later, x64**.

.NET, Windows App SDK and application assets are included. No Visual Studio, Developer Mode or separate runtime installation is required. Dependencies are extracted automatically on first launch.

The accompanying **.sha256** file contains the executable's SHA-256 hash.

## Included

- Local PulseChecks with full-face selection, optional factors and Skip.
- Protected local storage, privacy acknowledgement, retention, history and CSV export.
- The continuously animated nebula breathing exercise, with breathing-synchronized expansion and reduced motion.
- Optional Windows notifications with five face actions or the two-button layout.
- **Optional motivational notifications:** random short messages, editable message list, configurable spacing, preview and an Off switch. They start Off.
- Responsive layouts and tray reopening.

## Important notes

- **Unsigned preview:** Windows/SmartScreen or organizational policy may warn or block it. Verify the checksum and follow your organization's policy.
- The standalone app has a separate persistent local profile. It does not import development/testing data, and no personal data is included in the download.
- Keep the EXE in its chosen folder so Windows can reopen it from notifications. Quit before replacing it.
- Notifications require RUOK to be running, including in the tray. Windows controls banners, Notification Center and Do Not Disturb.
- The previously observed intermittent native shutdown fault remains under investigation. This release is not production-certified; clean-machine and ARM64 certification and code signing remain future work.
- RUOK is a reflection tool, not a medical device, diagnostic service, employee-monitoring tool or emergency service.
